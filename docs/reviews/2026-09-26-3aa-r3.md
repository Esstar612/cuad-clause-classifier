## Issues, ranked by severity

1. **(Correctness) The plan will break existing tests.**
   - Under the plan, `record_scores` reads `rec["prompt_version"]`. The test helper `_record` (tests/test_llm.py:430-436) builds records without that key.
   - The tests that go through `record_scores` or `run_health` would then fail with KeyError. That includes the reparse test, `test_build_frame_uses_reparsed_not_stored_scores` and `test_a_worse_retry...`.
   - `test_run_health_missing_field_raises[local_ids]` would still pass, but for the wrong reason.
   - Fix: add `"prompt_version": "v1"` to the helper.

2. **(Correctness, LLM behavior) Timeouts are hard to spot in `retry_errors`.**
   - `retry_errors` stores only the error text.
   - Claude timeouts are recorded as `"connection: Request timed out."` (APITimeoutError is caught as a connection error, clients.py:134).
   - Gemini timeouts are recorded as `"connection: " + str(httpx exception)`. That text can be empty or vary.
   - Server-side timeouts appear as `"408: ..."` or `"504: ..."`.
   - The plan doesn't say how the check matches these. Fix: count any `connection:`, `408` or `504` entry in a smoke attempt as a latency breach, and test it with these exact strings.

3. **(Pre-registration, needs your decision) What happens if you decline past $100?**
   - Suppose the combined option fits under $150 but projects above $100, while Gemini-only projects under $100.
   - As written, declining the combined option triggers the fallback, which removes v4 for both models. There is no step down to Gemini-only.
   - This has to be settled before the gate prints.

4. **(Pre-registration) The smoke has no rule for parse failures.**
   - Verification expects 0 parse failures, but the stop condition doesn't say what a failure means.
   - Suggested rule, to be written down before the smoke: a segment still unparsed after its retry excludes that model, the same as a rejected schema.
   - The gate's cost figures should also sum all attempts, so a retry's cost is counted.

5. **(Consistency, cost) The rebuild commands can overwrite cited files or spend money.**
