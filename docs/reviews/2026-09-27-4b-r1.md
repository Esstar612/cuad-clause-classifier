## Issues, by severity

### 1. Correctness
**a. Runtime (main issue).**
- `Part.__init__` always runs `ap_metrics` over the resamples. That is one sklearn `average_precision_score` call per resample and label (bootstrap.py:91-95), for 4 parts per model.
- At 10,000 resamples that is about 2.6M calls per compare (10,000 x 33 labels x 4 parts x 2 models). The self-check alone costs as much as a real compare.
- My rough guess, not a measurement, is on the order of an hour per compare, and several hours for all four. "Several minutes" is not credible. Timing the 4a compare and multiplying by 5 gives a local figure.
- None of these AP arrays supports a claim:
  - LLM minus baseline AP is omitted under Rule D.
  - Gemini minus Claude AP is "not interpreted".
- If AP is skipped, `macro_ap` becomes NaN. Then `all_zero` (`NaN == 0`) prints False on the self-check, so `macro_ap` has to leave the compare metrics entirely, not just be NaN-filled.

**b. Stale method string.**
- `compare` prints `METHOD` and writes it to JSON. `METHOD` says 2000 resamples (evaluate.py:30, 291, 313).
- The plan says the JSON "gains" a method field. The existing field has to be replaced with the 10,000-resample method, in both the printout and the JSON. Otherwise a wrong figure will reach results.md.

**c. Self-check misses the adjusted bounds.** `all_zero` does not include the adjusted bounds, yet step 5b and the Verification section rely on "all zero".

**d. `src.report` will pick up the self-check file.** Globbing `compare_*.json` also picks up `compare_baseline_vs_baseline.json`, which already exists. Name the three files explicitly.
