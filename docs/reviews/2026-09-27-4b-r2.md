## Findings, by severity

1. **Core logic not shown (CLAUDE.md, and needed for correctness).** `Part.scope()` and the new lines in `Part.__init__` are elided (`...` and a comment). `scope()` is metric logic and its current loop breaks without macro_ap. Show it. The summary should be built as `[m for m in SCOPE_METRICS if m in points]`, which keeps the JSON key order of `evaluate model` unchanged.

2. **The toy `compare` test cannot run as described (missing test detail).** Redirecting the data paths is not enough:
   - `compare` calls `label_sets`, which reads `spans.parquet` and `splits.parquet` and looks up the 17 `SHIFT_MEASURABLE_LABELS` by name, so a toy label order raises a KeyError.
   - `load_predictions` needs `label_order` in the parquet metadata.
   - `build_parts` makes a `Part` per shift type. If the toy data has no Franchise or no Transportation contract, `resample_weights` calls `np.concatenate([])` and raises a ValueError.

   The test needs to:
   - monkeypatch `src.evaluate.label_sets`;
   - write the toy files with `label_order` metadata;
   - include at least one Franchise and one Transportation contract in the toy shift file.

3. **Provenance (internal consistency).** Step 5b tees the 10,000-resample self-check into `data/processed/eval_compare_self.txt` and overwrites `data/eval/compare_baseline_vs_baseline.json`. `results.md:170` cites that file as the 4a 2,000-resample check. Either give the new check its own file name (for example `eval_compare_self_10k.txt`) or update line 170 in the write-up.

4. **The method text loses information.** `COMPARE_METHOD` no longer says "percentile 95% intervals", and it does not give the adjusted level. It goes into every compare JSON and into `results.md`. Add "percentile 95% intervals" and "adjusted level 99.58%".

5. **Rule D flag missing (pre-registration).** The validation table has a "Macro-AP (33)" column. The LLM values there are the 3ag "sparse" values (0.5764 and 0.6017), and Rule D requires them to be flagged as sparse lower bounds. Section 6 flags AP only in the new report tables.
