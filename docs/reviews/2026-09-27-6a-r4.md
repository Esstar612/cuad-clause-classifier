## Required changes
1. **Load from the pinned local snapshot, not the hub ID** (plan:125-131, and `tokens`).
   - Resolve the path with `snapshot_download(hub_id, revision=rev, allow_patterns=ALLOW, local_files_only=True)` inside a small `snapshot_path(key)` helper, and pass that path to `from_pretrained`. The tests patch the helper.
   - Why:
     - legal-BERT and DeBERTa-v3-base likely ship only `pytorch_model.bin`. For a hub ID whose repo has no safetensors file, recent transformers releases can start a background "auto-conversion" thread that asks the Hub to open a conversion pull request. That is a network side effect.
     - Loading by hub ID also makes network checks at the start of every multi-hour run.
     - A local load uses exactly the files that `fetch` downloaded and pinned.
2. **Enforce the pre-registered fp32** (plan:26).
   - In transformers v5, `from_pretrained` loads in the checkpoint's dtype by default.
   - Call `model.float()` in `load_encoder` and record the parameter dtype in `trained.json` and `probe.json`, so the recipe does not depend on the library version or the checkpoint.

## Optional notes
- **torch version.** Declare `torch>=2.6`. Recent transformers refuse to load `.bin` weights with an older torch (the `torch.load` safety check). A fresh install already satisfies this, but the bound makes the requirement explicit.
- **Dropbox.** The project lives in Dropbox, and three sets of weights (roughly 2 GB) will sync to the cloud even though git ignores them. Before `train`, mark the directory as ignored with `xattr -w com.dropbox.ignored 1 models/transformer`. Git still tracks its metadata.
- **Sleep.** Prefix the `probe` and `train` commands with `caffeinate -i` so macOS does not suspend a multi-hour run.
- **Weight decay.** Say in the pre-registration that it applies to every parameter. The common Hugging Face recipe exempts biases and LayerNorm weights, so a reader might otherwise assume that.
- **Impractical training time.** Runs step 4 (plan:448) offers no recipe change for this case, since the OOM fallback does not reduce time. State that any time-driven change, such as dropping an encoder, would be a logged amendment made before any training.
- **Probe speed.** `probe` tokenizes all 34,871 train texts one at a time (plan:226). A single call to `encode` over the batch is faster and gives the same lengths.
